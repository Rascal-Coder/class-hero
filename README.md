# 下课别跑

Cocos Creator **3.8.8** 竖屏 2D 游戏。把尺子、橡皮、回形针、圆规组合成文具武器，守住放学后的操场。全部角色和文具由 Cocos Graphics 绘制，不需要外部贴图或网络服务。

## 运行

用 Cocos Creator 3.8.8 打开此文件夹，双击 `assets/scenes/Classroom.scene`，点击预览。工程已带场景、脚本、音效及资源元数据。

Web 构建：在 PowerShell 中执行 `./build.ps1`。安装 Node.js 后执行 `npm run preview`，访问 <http://localhost:7459>。浏览器版本来自实际 Cocos 引擎构建。

## 操作

- 将小卖部商品拖到书包绿色格或课桌暂存格，成功放下才扣钱。
- 点击商品查看详情，也可购买并自动合成或寻找接口安装。握把不在小卖部出售。
- 每把武器只有一个握把。拖动握把按整把武器判断并移动；其他部件仅判断自身占格。初始尺子发射器可单独拖起并显示原位三格绿色，但只能放回原安装位，不能拆到暂存区或带动整枪。
- 额外发射器向上叠加；枪托接左侧并占两格，瞄具接最上方，弹匣接发射器下方中部，下挂手榴弹接枪口下方。
- 同类同级部件拖到一起合成升一级，最高 5 级。书包和暂存区均可合成，初始发射器可作为合成目标；不同等级不会互相替换。
- 其他配件只能手动拖拽拆下重装；有下游配件时先拆末端。点击、右键和详情按钮均不能拆件。纸团和牛奶独立放置。
- 暂存区的物品不参与战斗。无握把连接的发射器不提供火力。
- 拖握把时绿色表示整枪可落下的握把位置；拖其他部件时绿色覆盖部件完整占格。黄色四角标出当前落点，红色角框和叉号表示不可放置。
- 暂存区为白边蓝底方格，物件进入可用格时缩放居中预览。合成目标带星标，完成后闪光并显示升级星级；拖拽和合成通过画面反馈。无效拖放自动回弹，资金不足时仅保留「资金不足」文字。
- 点击「去操场」开始自动回合战斗：先逐个投掷纸团/下挂手榴弹，再逐根枪管射击，全部命中结算后敌方依次前进一步，进入各自攻击范围才放技能。升级增加伤害，不增加同一枪管的射击次数。
- 前两波有 2–3 只敌人，第 3 波起出现精英，每 5 波有 BOSS；近身、远程、冲刺、精英连击和 BOSS 蓄力攻击各有区别。每两波选择一次奖励，共 15 波。
- 空格开战/暂停，Esc 返回/暂停，R 刷新，1/2/3 购买并自动安装，Tab 和 Enter 导航按钮。

每次整备操作自动保存；重新打开页面回到最近一次整备检查点。旧存档中合法连接的初始部件会自动补上固定标记；存在多个握把、握把已拆下或悬空配件的旧布局会重置。暂停菜单可以重开并重置当前局。

## 与参考视频的对应

采用 6×5 装备格、10 个暂存位、3 个商店位、武器接口拼装和红绿放置提示的结构。原视频的属性变化和组合过程记录在 [reference/analysis.md](reference/analysis.md)；当前拼装、合成和回合规则以 [docs/need-change.md](docs/need-change.md) 为准，其中被注释的怪物外观修改未启用。

原视频仅 66 秒，展示到第 3 波。后续敌人数值、未展示配件规则、掉落概率和广告奖励不能从这段视频完整确定。15 波关卡平衡、奖励效果、牛奶回复、下挂手榴弹与敌人技能数值为可调整的补全规则。没有接入广告 SDK，视频中的广告免费领取位使用普通零花钱购买。

## 验证与代码

`npm test`（或 `node tools/test.mjs`）运行无渲染依赖的组合和回合战斗测试；`npm run typecheck`（或 `node tools/typecheck.mjs`）使用 Creator 生成的引擎类型检查。先用 Creator 打开或构建工程，生成 `temp/tsconfig.cocos.json`。

构建并启动预览后，`node tools/browser-smoke.mjs --journey` 验证实际浏览器拖拽、合成、回弹、存档、战斗、触控和不同窗口尺寸，截图输出到 `test-results/`。浏览器测试使用本机 Playwright，可通过 `CODEX_DEPENDENCIES` 和 `CHROME_PATH` 指定依赖目录及浏览器路径。

| 文件 | 职责 |
| --- | --- |
| `assets/scripts/core/Inventory.ts` | 固定核心、占格、接口图、同级合成、属性、暂存、存档验证 |
| `assets/scripts/core/Battle.ts` | 道具/射击/敌方回合队列、命中暴击、精英/BOSS 技能、波次结算 |
| `assets/scripts/ClassroomGame.ts` | Cocos 输入、界面、拖拽交易、状态与存档 |
| `assets/scripts/Painter.ts` | 极简校园角色、文具和界面的原生图形绘制 |
| `tools/setup.mjs` | 可重复生成场景和资源 UUID |

构建方式参考 [Cocos 官方命令行构建文档](https://docs.cocos.com/creator/3.8/manual/zh/editor/publish/publish-in-command-line.html)。
